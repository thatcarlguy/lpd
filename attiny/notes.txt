for the interlock, use rising/falling edge of async interrupt (only on PB2, PA2, PA6) to turn off laser, switch light, and change digital output
when interrupt is tripped, put a square wave for calibration confirmation on the voltage output.

#include <avr/io.h>
#include <avr/interrupt.h>

// Define which pin is used
#define INTERRUPT_PIN PIN2_bm

void setup() {
    // 1. Configure the pin: Pull-up enabled + Falling edge sensing
    // Note: Px2 and Px6 have full asynchronous detection capability
    PORTA.PIN2CTRL = PORT_PULLUPEN_bm | PORT_ISC_FALLING_gc;
    
    // (Optional) Configure an output pin to see the result (e.g., PA3)
    PORTA.DIRSET = PIN3_bm;

    // 2. Enable global interrupts
    sei();
}

// Common Interrupt Service Routine (ISR) for all pins on PORTA
ISR(PORTA_PORT_vect) {
    // Check if the interrupt was triggered by PA2
    if (PORTA.INTFLAGS & INTERRUPT_PIN) {
        
        // Toggle an LED on PA3 to indicate the interrupt occurred
        PORTA.OUTTGL = PIN3_bm;

        // Clear the interrupt flag by writing a 1 back to that specific flag bit!
        PORTA.INTFLAGS = INTERRUPT_PIN;
    }
}

SPI (24.3.1 in manual)
Initialize the SPI to a basic functional state by following these steps:
1. Configure the SS pin in the port peripheral.
2. Select SPI Master/Slave operation by writing the Master/Slave Select bit (MASTER) in the Control
A register (SPIn.CTRLA).
3. In Master mode, select the clock speed by writing the Prescaler bits (PRESC) and the Clock
Double bit (CLK2X) in SPIn.CTRLA.
4. Optional: Select the Data Transfer mode by writing to the MODE bits in the Control B register
(SPIn.CTRLB).
5. Optional: Write the Data Order bit (DORD) in SPIn.CTRLA.
6. Optional: Setup Buffer mode by writing BUFEN and BUFWR bits in the Control B register
(SPIn.CTRLB).
7. Disable the multimaster support in Master mode, write '1' to the Slave Select Disable
bit (SSD) in SPIn.CTRLB.
8. Enable the SPI by writing a '1' to the ENABLE bit in SPIn.CTRLA.

24.3.2.1.1: If SSD in SPIn.CTRLB is one, the SPI does not use the SS pin, and it can be used as a regular I/O pin, or by other peripheral modules
