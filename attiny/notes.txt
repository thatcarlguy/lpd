
Pinout:
  PA0 - UPDI        Programming
  PA1 - SPI/MOSI    RS485 output, Analog output control
  PA2 - SPI/MISO    RS485 output, Analog output control
  PA3 - SPI/SCK     RS485 output, Analog output control
  PA4 - AIN6        Analog input for laser PD feedback
  PA5 - TCB0        PWM output to control TEC                (https://wolles-elektronikkiste.de/en/tinyavr-series-part-2-timer-a-b-ccl-slpctrl#timer_b)
  PA6 - DOUT        Digital output for laser on/off control
  PA7 - AIN7        Analog input for board temperature
  PB0 - TCA0        Counter
  PB1 - DOUT        Digital output for Analog/Digital output select: 
                                                High: Digital send, Analog disabled
                                                Low:  Digital recieve, Analog send
  PB2 - DIN         Digital input for interlock
  PB3 - DOUT        Digital output for status LED
